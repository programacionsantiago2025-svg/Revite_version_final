# REVITE 

A desktop application developed in Python using Flet for vehicle, customer, and reservation management.  
This system allows efficient administration of cars, client registration, reservation creation, and database storage using SQLite.
# Features
- Customer registration and management
- Vehicle registration and administration
- Reservation creation and cancellation
- Database storage with SQLite
- Graphical desktop interface using Flet
- Data persistence
- Modular project architecture
- Object-Oriented Programming implementation:
  - Abstraction
  - Encapsulation
  - Inheritance
  - Polymorphism

# Prerequisites

Before running the project, install:

- Python 3.10 or later
- Required modules

Install dependencies:

```bash
pip install flet
```
Or use requirements.txt:

```bash
pip install -r requirements.txt
```

# How to Run the Script

Clone repository:

```bash
git clone https://github.com/programacionsantiago2025-svg/Revite.git
```

Enter folder:

```bash
cd Revite
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run project:

```bash
python -m src.views.page
```
